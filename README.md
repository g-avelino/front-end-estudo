# ONG Esperança - Projeto Front-end

## 📑 Descrição
Este projeto foi desenvolvido como prática de **estruturação de sites front-end**, aplicando HTML5 semântico, validações nativas e organização de assets.  
O objetivo é criar um site institucional para a ONG Esperança, com páginas de apresentação, projetos e formulário de cadastro.
