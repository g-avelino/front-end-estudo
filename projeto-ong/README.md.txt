## 🛠️ Tecnologias Utilizadas
- **HTML5**: estrutura semântica e validação nativa (`required`, `pattern`, `type`).  
- **CSS3**: estilização e responsividade.  
- **JavaScript**: interatividade básica.  
- **WebP**: imagens otimizadas para performance.  

---

## ✅ Validação W3C
- Todos os arquivos foram submetidos ao **W3C Validator**.  
- Correções aplicadas:
  - Inclusão de `alt` em imagens.  
  - Associação correta de `<label>` com `for`.  
  - Definição de `lang="pt-BR"`.  
  - Ajuste de entidades HTML (`&copy;`).  
- Resultado: **sem erros críticos**, apenas avisos informativos.

---

## 📋 Funcionalidades
- Página inicial com apresentação da ONG.  
- Página de projetos com campanhas e voluntariado.  
- Formulário de cadastro com validações nativas para CPF, CEP e telefone.  
- Estrutura modular de pastas para fácil manutenção.

## 🚀 Como Executar
1. Clone ou copie a pasta `projeto-ong`.  
2. Abra o arquivo `html/index.html` em qualquer navegador.  
3. Certifique-se de que os arquivos CSS, JS e imagens estejam nos diretórios corretos.
